เชื่อมต่อ Google Drive

ต้องสร้าง OAuth Client ID ของตัวเองใน Google Cloud Console (ฟรี) แล้ววางที่นี่ ข้อมูล vault ที่เข้ารหัสแล้วจะถูกเก็บใน App Data folder ซึ่งมองไม่เห็นใน Drive UI ปกติ

วิธีสร้าง Client ID: ไปที่ Google Cloud Console → Credentials → สร้าง OAuth client ID ประเภท "Web application" → ใส่ URL ที่โฮสต์แอปนี้ใน "Authorized JavaScript origins" → เปิดใช้งาน Google Drive API ในโปรเจกต์เดียวกัน

เชื่อมต่อ Google Drive Picker

การเลือกไฟล์จาก Google Drive โดยตรงต้องใช้ Google API Key เพิ่มเติม (คนละตัวกับ OAuth Client ID) สร้างได้ฟรีในโปรเจกต์เดียวกัน

วิธีสร้าง: ไปที่ Google Cloud Console → Credentials → Create Credentials → API key → กด "Restrict key" → จำกัดให้ใช้ได้เฉพาะ "Google Picker API" และเฉพาะ HTTP referrer ที่เป็น URL ของแอปนี้ → อย่าลืมเปิดใช้งาน "Google Picker API" ในเมนู Library ด้วย
